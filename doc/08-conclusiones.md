# 8. Conclusiones

## Conclusión de David Crisbasianu Petronga

Con este proyecto he podido llevar una idea propia a una aplicación web real, aprendiendo a crearla con Spring Boot y a organizar el código en capas con responsabilidades separadas.

Al principio me costó entender cómo se conectaban el controlador, los servicios, los casos de uso y el repositorio, pero una vez comprendido me ha resultado mucho más sencillo añadir nuevas funcionalidades, como la consulta de tareas por prioridad. Me gustaría seguir mejorando la aplicación en el futuro, por ejemplo guardando los datos en una base de datos.

## Conclusión de Álvaro Cabrejas Ormeño

Este proyecto me ha servido para poner en práctica lo que hemos visto en la asignatura, desarrollando una aplicación completa paso a paso, desde la creación del proyecto hasta su documentación.

He aprendido a validar los datos que llegan a la aplicación y a mostrar mensajes de error claros cuando algo falla, algo que mejora mucho la experiencia del usuario. Lo que más me ha costado ha sido configurar MapStruct junto con Lombok, pero al final he entendido cómo funcionan y lo útiles que son para ahorrar código repetitivo.

## Conclusión de Samuel Alonso Álvarez

Hemos desarrollado una aplicación web desde cero, partiendo de una idea sencilla para dar solución a una necesidad que no está cubierta de forma específica por otras aplicaciones.

En este proyecto hemos puesto en práctica los conocimientos adquiridos durante la asignatura, desarrollando una aplicación con capas bien diferenciadas y responsabilidades separadas. Esta organización permite conseguir un código más mantenible, facilitar futuras ampliaciones y mejorar la escalabilidad del proyecto.
